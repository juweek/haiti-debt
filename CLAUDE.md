# CLAUDE.md: working in haiti-explorer

Interactive explorer of Haiti's independence debt ("double debt", 1825–1888) and
the US loans that followed (1922–1947), plus the modern World Bank series. Audience:
social-media readers and Haitians / Haitian Americans who want a reliable reference.
**The one hard rule: never show a number that isn't traceable to `data/SOURCES.md`.**

## Stack and conventions

- Plain JavaScript + JSX (no TypeScript). React 19, Vite 6. d3 *modules* only
  (`d3-scale`, `d3-shape`, `d3-array`, `d3-format`); never import the `d3` bundle.
- Multi-page Vite build: `vite.config.js` → `build.rollupOptions.input` lists
  `index.html` (explorer) and `sources.html` (sources & method). To add a page,
  add an HTML file at the root, a `src/<name>-main.jsx` entry, and an `input` key.
- `base: './'` so `dist/` works from any path (GitHub Pages, Netlify, a subfolder).
- Charts are hand-built SVG in React; d3 only computes scales and paths.

## Data pipeline

`npm run data:refresh` runs `scripts/build-data.mjs`:

1. Tries to re-download the NYT CSV, two WDI series and eight IDS creditor series into `data/raw/`
   (falls back to the vendored copy on any error; `--offline` skips this).
2. Parses the NYT CSV (payments, remaining double debt, GDP, fx, CPI), the
   Henochsberg/receivership subset, and the World Bank JSON.
3. Builds one row per year 1825–1947 (`years`) and 1970–2024 (`modern`, with
   `cred: {mlt, imf, ven, oth, prv}` in US$ M; the groups must sum to IDS DECT).
   `% of GDP = francs ÷ franc-per-$ ÷ GDP($)`. `null` means "no data", not zero.
4. Computes `stats` (totals, peak, medians, 150M francs in 2021 $).
5. **Asserts** the stats match the fact-checked figures (≈112M francs, ≈$560M,
   11.6% peak in 1840, 2.5% median, ≈3× GDP in 1826, last payment 1888). If a
   source changes, the build fails: update the facts and `data/SOURCES.md`
   deliberately, don't loosen the check.
6. Writes `src/data/explorer.json` and `public/data/haiti-debt-explorer.{json,csv}`.

Key facts that aren't in a CSV live in `scripts/sources.mjs` with source ids.
To add a number: add the source to `SOURCES`, the value to `FACTS` (or an event),
document it in `data/SOURCES.md`, then reference it from components via
`data.facts.<id>` — never type the number into a component.

## Gotchas

- Payments exist only 1825–1888 (NYT). GDP only to 1915. 1916–1947 has no GDP,
  so the chart shades it and leaves it empty; the year note explains each gap.
- "Median ≈2.5%" is over years with a recorded payment (53 years). Counting zero
  years it's 2.0%. The sources page states both.
- 1825 shows no payment: the first installment came from the loan, and the NYT
  counts it through the loan repayments.
- The "all external debt" line is digitized from Henochsberg's Fig. 14 (±1M francs).
- The $21B lost-growth low end and Aristide's $21.7B demand are different things.
- 1888 (end of double debt) and 1947 (end of US loans) are different debts.

## Design rules

- Look: Gourmet Data chart style. Colors are `PAL` in `src/model.js` / CSS vars in
  `styles.css`, copied from `/workspace/email-charts/gd_chart.py` (`C`) and
  `/workspace/haiti-debt/hd_render_cmp.py` (light tints). Don't invent new colors.
  Headlines 700 IBM Plex Sans Condensed; body IBM Plex Sans; annotations Condensed
  Medium Italic in `story` with a paper halo and a thin leader + arrowhead
  (`gd_annostyle.py` style "A").
- Units: "Amount owed" over the full span uses two y-axes (francs left, US$ right),
  each drawn only over its own years. Never put both on one scale, never draw across
  the 1916–1969 gap.
- Mobile-first; check at 390px (iPhone) and 1280px. The page must never scroll
  sideways and SVG text must stay inside the chart: `scripts/screenshots.mjs` fails otherwise.
- Pills wrap (no horizontal scroller, no edge fades). Titles and subtitles are
  computed from `data.stats` in `titlesFor()`; annotation numbers come from data too.
- Accessibility: the native range input is the keyboard control (arrows ±1,
  Page Up/Down ±10, Home/End); the SVG is `aria-hidden`, the year note is
  `aria-live`, pills are `role=radio`.
- Touch: the SVG uses `touch-action: pan-y`, so horizontal drags scrub and
  vertical drags scroll. The tooltip hides 1.8s after a touch ends.
- URL hash holds the view: `y` year, `s` subject, `m` measure, `e` era, `off` unchecked series.
